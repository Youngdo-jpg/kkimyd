# 블록깨기 (Breakout)

Python + Pygame으로 만든 블록깨기 게임입니다.

## 실행 방법

```bash
pip install -r requirements.txt
python breakout.py
```

## 조작법

- `←` / `→` 또는 `A` / `D`: 패들 좌우 이동
- `Space`: 공 발사
- `R`: 게임 오버 또는 승리 후 재시작
- `Esc`: 게임 종료

## 게임 규칙

- 공을 튕겨서 화면 위쪽의 모든 블록을 깨면 승리합니다.
- 공이 패들 아래로 떨어지면 목숨이 하나 줄어듭니다.
- 목숨이 모두 소진되면 게임 오버입니다.
